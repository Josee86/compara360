# Dominio y publicación

## URL gratuita inicial
GitHub Pages proporciona un subdominio con formato:
`https://TU-USUARIO.github.io/compara360/`

## Dominio propio
Para usar `compara360.com` hay que registrar y renovar el dominio con un registrador. No presupuestamos que sea gratuito. No uses ofertas de "dominio gratis" que exijan hosting de pago, tarjeta bancaria, renovación automática o transferencia posterior costosa.

## Comprobación
Una vez publicado el repositorio, confirma que:
- la web carga por HTTPS;
- el selector de país conserva la selección;
- se ve claramente el aviso de datos ficticios;
- no hay claves secretas dentro del código público.
