# Aviso de afiliación — texto para activar cuando existan enlaces afiliados

COMPARA360 puede recibir una comisión si realizas una compra a través de determinados enlaces de esta web. Esto no incrementa necesariamente el precio que pagas. La existencia de una comisión no debe alterar el orden de los resultados: las ofertas se ordenarán según el criterio de comparación publicado, incluyendo el coste de envío cuando esté disponible.

**No publiques este aviso como prueba de que ya existen acuerdos.** Actívalo y adáptalo cuando haya programas de afiliación aprobados y enlaces reales.
