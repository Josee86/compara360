# Publicar COMPARA360 gratis con GitHub Pages

1. Entra en https://github.com/ y crea una cuenta gratuita si aún no tienes una.
2. Pulsa **New repository** y nómbralo `compara360`.
3. Selecciona **Public** y crea el repositorio.
4. Descomprime este ZIP y sube el contenido interior de la carpeta `COMPARA360`, incluida la carpeta oculta `.github`.
5. Pulsa **Commit changes**.
6. Abre **Settings → Pages** y selecciona **GitHub Actions** como método de publicación.
7. Abre **Actions** y espera a que termine el despliegue.
8. GitHub mostrará la URL pública, normalmente `https://TU-USUARIO.github.io/compara360/`.

No compartas contraseñas, códigos, tokens ni claves API. Cuando esté publicada, comparte solo la URL pública.
